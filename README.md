## 🎮 Games & experiments

| Project | What I'm building | Explore |
| :--- | :--- | :--- |
| **[Sekampfire](https://github.com/SekaFaji/Sekampfire)** | A four-season pixel-art survival game about gathering wood, keeping a campfire alive, crafting, and expanding your camp. | [Play](https://sekafaji.github.io/Sekampfire/) |
| **[Sekasma](https://github.com/SekaFaji/Sekasma)** | A touch-driven idle plasma-ball game, with a custom pixel renderer and a tested game economy. | [Play](https://sekafaji.github.io/Sekasma/) |
| **[Pixel Keep](https://github.com/SekaFaji/Pixel-Keep)** | A playable castle-defense prototype with aimed arrows, defensive upgrades, and enemy waves. A redesign named *Sekarrows* is in planning. | [Play](https://sekafaji.github.io/Pixel-Keep/) |
| **[Sekavore](https://github.com/SekaFaji/Sekavore)** | A browser-based incremental mining prototype with upgrades and locally saved progress. | [Source](https://github.com/SekaFaji/Sekavore) |
